1. ¿Qué se pidió y qué cambió?

En la pantalla del Kiosko de precios (donde el cliente escanea el código de barras de un producto) se pidieron dos ajustes:

AjusteAntesAhora
1. Producto exentoLa fila IVA mostraba 0,00 Bs.La fila IVA muestra la palabra «Exento».
2. TarifaMostraba todas las listas de precios del producto, aunque el Precio mostrado era el más alto.Muestra solo la lista de precios que aporta el precio más alto (el que se ve en Precio).
Producto exento = el producto no tiene impuestos aplicables, o todos sus impuestos están en 0 %. Un impuesto de tipo «código» (fórmula) nunca se considera exento, porque puede calcular un importe distinto de cero. La palabra «Exento» solo se muestra si está activo Calcular IVA.
Empates de precio: si dos listas dan exactamente el mismo precio, gana la de menor secuencia y, si también empatan, la de menor id (el orden normal de las listas de precios). Si ninguna lista fija precio y se usa el precio de venta de la ficha, la fila Tarifa no se muestra.

2. Configuración previa (antes de hacer las pruebas)

  1. Instalar el módulo «Binaural Kiosko» (Aplicaciones → quitar el filtro «Aplicaciones» → buscar Binaural Kiosko). Se instalan también Product Price Checker y la localización de tasas de Venezuela.
  2. Tu usuario necesita el permiso «Price Checker». Sin él, la sección de configuración y el menú no aparecen. Ajustes → Usuarios y empresas → Usuarios → abrir tu usuario → pestaña Permisos de acceso → marcar el grupo Price Checker (puede requerir modo desarrollador) → recargar la página con F5.
    El usuario de kiosko kiosko (solo consulta) ya trae este permiso desde la instalación.
  3. Activar la función «Listas de precios» de Odoo (Ventas → Ajustes → Listas de precios) y crear al menos dos listas con precio fijo para un mismo producto.
  4. Revisar la configuración del kiosko: Ajustes → Comprobador de precios → Configuración del verificador de precios. Para estas pruebas deben estar marcados:
    • Calcular IVA (Precio, IVA, Total y Ref.): sin esto no hay fila IVA, ni «Exento».
    • Mostrar precio de venta del producto: sin esto no se ve la fila Precio.
    • Mostrar lista de precios de productos: controla si se ve la fila Tarifa.
    • En Listas de precios, seleccionar las dos listas de prueba.
  5. Productos de prueba (con código de barras): (a) uno sin impuestos o con impuesto 0 %; (b) uno con IVA 16 %; (c) uno con precio fijo en dos listas distintas (por ejemplo 120 y 150), con IVA 16 %.

3. Pruebas paso a paso

Abrir la pantalla del kiosko desde el menú Comprobador de precios o con la URL /login/checker. En cada caso: escribir (o escanear) el código de barras y pulsar Ir.

Caso 1 — Producto exento muestra «Exento» Ajuste 1

  1. Con Calcular IVA activo, ingresar el código del producto sin impuestos.
  2. Observar la tabla «Información del producto».

Resultado esperado: la fila IVA dice Exento (no 0,00); el Total es igual al Precio.

Caso 2 — Producto con IVA muestra el importe Control

  1. Ingresar el código del producto con IVA 16 %.

Resultado esperado: IVA con importe numérico ($ 16,00 sobre un precio de 100) y Total $ 116,00. Nunca debe decir «Exento».

Caso 3 — Tarifa muestra solo la lista ganadora Ajuste 2

  1. Ingresar el código del producto que está en dos listas (Detal = 120, Mayorista = 150).

Resultado esperado: la fila Tarifa muestra solo «Lista Mayorista UI» (la del precio más alto, 150). IVA $ 24,00 y Total $ 174,00 corresponden a 150 + 16 %.

Caso 4 — Casos de borde (recomendados) Complementario

  • Calcular IVA apagado: la fila IVA no se muestra (nunca aparece «Exento»).
  • Empate de precio entre dos listas: se muestra la de menor secuencia.
  • Producto sin ninguna lista aplicable: se usa el precio de la ficha y la fila Tarifa no aparece.
  • Idioma: con el usuario en español la palabra se ve «Exento»; en inglés se vería «Exempt».

4. Consideraciones para las pruebas

  • Los importes salen en la moneda de la compañía (en estas pruebas, USD; en producción venezolana, bolívares).
  • La fila Tarifa solo muestra el nombre de la lista, sin importes, y solo si «Mostrar lista de precios de productos» está activo.
  • Si tras dar el permiso la sección sigue sin verse, recargar con F5 o cerrar y abrir sesión.
  • Al abrir Ajustes puede salir un aviso de Odoo sobre «desactivar la configuración de la lista de precios». Cerrarlo y no guardar (ver observaciones).
  • Las pruebas de esta guía se hicieron en una base de desarrollo nueva; los datos son de prueba.
